# ប្រព័ន្ធស្រង់ និងគ្រប់គ្រងទិន្នន័យបុគ្គលិកអប់រំ (Talosenchey Education Staff Management System)
### រដ្ឋបាលស្រុកតាលោសែនជ័យ • ការិយាល័យអប់រំ យុវជន និងកីឡា

ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងសម្រាប់គ្រប់គ្រង ស្រង់ទិន្នន័យ ស្វែងរក កែប្រែ និងបោះពុម្ពព័ត៌មានលម្អិតផ្លូវការរបស់មន្ត្រីរាជការ **ក្របខណ្ឌ**, **កិច្ចសន្យា**, និង **គ្រូកិច្ចព្រមព្រៀង** ស្របតាមទម្រង់ក្រសួងមុខងារសាធារណៈ និងក្រសួងអប់រំ យុវជន និងកីឡា (២៣ ជួរឈរ) ព្រមទាំងភ្ជាប់ជាមួយ **Supabase Cloud Database** និង Deploy លើ **GitHub Pages**។

## ⚡ ការតភ្ជាប់ជាមួយ Supabase Cloud Database

កម្មវិធីបានបំពាក់ម៉ូឌុលតភ្ជាប់ជាមួយ Supabase Cloud រួចជាស្រេច៖
1. **បង្កើតគម្រោងលើ Supabase:**
   - ចូលទៅកាន់ [supabase.com](https://supabase.com) ហើយបង្កើត Project ថ្មីមួយ។
2. **បង្កើតតារាង (Run SQL Migration):**
   - ចូលទៅកាន់ **SQL Editor** ក្នុង Supabase Dashboard
   - ចម្លងកូដពីឯកសារ `supabase_schema.sql` (ឬចុចប៊ូតុង **«ចម្លងកូដ SQL បង្កើតតារាង»** ក្នុង Web App)
   - ចុច **Run** ដើម្បីបង្កើតតារាង `staff_members` និង RLS Policies។
3. **ភ្ជាប់ទៅកាន់ Web App:**
   - ចុចលើប៊ូតុង **«Supabase: រៀបចំ»** នៅលើ Header នៃ Web App
   - បញ្ចូល **Project URL** និង **Anon / Public Key**
   - ចុច **«រក្សាទុក & ភ្ជាប់ទៅ Supabase»**
   - ចុច **«បញ្ជូនទិន្នន័យទាំងអស់ទៅ Cloud»** ដើម្បី Push ទិន្នន័យ ២១៣ នាក់ទៅ Cloud។
4. **សមកាលកម្មដោយស្វ័យប្រវត្តិ (Auto-sync):**
   - រាល់ការកែប្រែ បន្ថែម ឬលុបទិន្នន័យបុគ្គលិកលើតារាង នឹងត្រូវ update ទៅកាន់ Supabase ដោយស្វ័យប្រវត្តិ។
